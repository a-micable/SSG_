## 🎯 Usage Examples

### Quick Start
```bash
# Clone
git clone https://github.com/a-micable/SSG.git
cd SSG

# Install
pip install -e .

# Create site
ssg init mysite
cd mysite

# Build
ssg build

# Serve
ssg serve
```

### Docker Usage
```bash
# Build image
docker build -t ssg .

# Use it
docker run -v $(pwd)/mysite:/site ssg
```

### Run Tests
```bash
pytest
# 59 passed in 1.85s ✅
```
