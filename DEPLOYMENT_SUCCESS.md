## 🚀 Usage

### Install
```bash
git clone https://github.com/a-micable/SSG.git
cd SSG
pip install -e .
```

### Create a Site
```bash
ssg init mysite
cd mysite
ssg build
ssg serve
```

### Run Tests
```bash
pytest
# All 59 tests pass! ✅
```
